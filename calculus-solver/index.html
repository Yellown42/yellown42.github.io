Derivative & Integral Solver (Lightweight)

Supports polynomials ≤ degree 3, axⁿ, sin(ax), cos(ax), e^(ax)

This lightweight AP Calculus helper computes derivatives and indefinite integrals for a small set of common classroom formats (polynomials up to degree 3, sin(ax), cos(ax), and e^(ax)).

It is not a full CAS: it uses simple parsing rules and is designed for quick checking and practice. Runs entirely in your browser—no data is saved.

Supported formats (with examples)
Polynomials (degree 0–3)
• 3x^2 - 4x + 1
• -x^3 + 2x - 7
• x, x^2, 5
Trig (whole expression must match)
• sin(2x), cos(-3x), sin(x)
Exponential (whole expression must match)
• e^(4x), e^(x), e^(-2x)
What is NOT supported
• Products like (x+1)(x-2) or x·sin(x)
• Quotients like (x^2+1)/(x-1)
• ln(x), tan(x), nested functions like sin(x^2)
• General parentheses/simplification (this is not a CAS)

Formatting tips: use x^n for powers. Spaces are okay. Unicode minus signs and “x²/x³” are normalized automatically.

How to Use

  • Enter a function using the supported syntax (examples are clickable above).

  • If an input isn’t supported, adjust it to match the supported formats list.

FAQ

Why doesn’t it handle every function?
This tool intentionally supports only common AP Calc forms so results stay predictable and easy to verify.

Is the integral constant included?
Yes—indefinite integrals include + C.

Does this store my function?
No. Everything runs locally in your browser.
