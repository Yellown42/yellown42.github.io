How to Use

  • Fill in any known values (with units) for v₀, v, a, t, and Δx.
  • Switch to 2D mode only if you want to solve x and y components separately.
  • Click Solve. If time is quadratic, the solver will list all valid times.
  • Check the Solution status message to see whether inputs are unique, multiple, or inconsistent.

FAQ

Why do I sometimes get two times?
Many motion problems lead to a quadratic in t, which can produce two valid solutions (for example, going up and coming down).

What does “inconsistent inputs” mean?
The provided values contradict the kinematics equations (often due to a sign, unit, or copied value issue).

Does this work for changing acceleration?
No—this tool is for constant acceleration only (standard AP kinematics).
